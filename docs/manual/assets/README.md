# 取扱説明書の画面写真

アプリ内ヘルプの `figure` ブロックへ `image: "ファイル名.png"` を指定すると、
同じ図解の直後に、このディレクトリのPNGが「画面例」として取扱説明書へ入る。

一つの章へ図解とは別の画面を追加するときは、独立したブロックを使う。

```ts
{
  type: "screenshot",
  image: "ファイル名.png",
  caption: "画面で確認できる内容の説明。",
}
```

`screenshot` は取扱説明書PDFだけに画像と説明を載せる。画像ファイルを
Reactから読み込まないため、アプリの配布物には含まれない。

- サブディレクトリや `..` は使わず、PNGのファイル名だけを指定する。
- 画像がまだ無い場合は警告を出し、その画面例を省略してPDF生成を続ける。
- 画像は縦横比を保ち、A4の本文枠へ収まる大きさで配置される。
