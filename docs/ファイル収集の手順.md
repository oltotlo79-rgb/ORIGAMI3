# 30件のファイルを用意する手順

最初に`origamisimulator.org`を開き、図形を1件描き、`Export`から名前の最後が`.fold`（今回使う種類を表す文字）のファイルとして指定先へ保存し、開き直して担当者へ知らせます。成功してから残りへ進みます。
自分で図形を描くのは、他の人の作品を無断で使わないためです。悪魔と1分ローズは使いません。

## まず1件だけ試す（10分程度）

1. ブラウザー（インターネットのページを見る画面）の上部にある住所欄へ `https://origamisimulator.org/` と入力し、Enterキーを押します。ソフトをパソコンへ入れる必要はありません。
2. `Origami Simulator`という名前の画面が出るまで待ちます。作者名が表示される場合は、`Amanda Ghassaei`であることも見ます。
3. 最初から見本が表示されていても保存しません。画面の上部か左側にある`File`を押し、その中の`New`、`New Pattern`、`Clear`の順に見ます。表示されたものを押し、何も描かれていない正方形を出します。
4. 画面上部か左右で`Grid`、`Snap`（線の端を決まった位置へ合わせる表示）、または`View`を押した中の`Grid`を押します。設定画面が出たら、`Grid Size`、`Grid Divisions`、`Set Grid`、`Configure Grid`のいずれかを押します。数字の欄なら`4`と入力し、数字の一覧なら`4`を押して、正方形を縦横4等分する位置を表示します。
5. `Edit`、`Draw`、`Crease Pattern`、`Add Crease`のいずれかを押します。`Valley`または`V`を押し、上辺の中央から紙の中心までと、中心から下辺の中央まで、谷折りを2区切り描きます。
6. 画面の上部か左側の`Export`を押します。なければ`File`を押し、その中の`Export`または`Save`を押します。`Export`は、ほかのソフトでも使える形で保存する表示です。
7. 保存方法の一覧が出たら、名前に小文字の`.fold`を含む項目を押します。`.fold`は、今回用意するファイル名の最後の部分です。
8. 保存先を選ぶ前に、Windowsの印が付いたキーを押しながら`E`を押します。エクスプローラー（ファイルとフォルダーを見る画面）が開きます。
9. 画面上部の場所を示す欄へ次を入力し、Enterキーを押します。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3
   ```

10. `verification`を開きます。なければ画面上部の「新規作成」から「フォルダー」を押し、`verification`と入力してEnterキーを押してから開きます。
11. `verification`の中へ同じ方法で`fold-samples`を作って開き、その中へ`04-origami-simulator`を作ります。すでにあるフォルダーは作り直しません。
12. ブラウザーへ戻ります。保存先を選ぶ画面が出ている場合は、上部の場所を示す欄へ次を入力し、Enterキーを押します。

    ```text
    C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples\04-origami-simulator
    ```

13. 名前の欄へ`origami-simulator-01.fold`と入力します。画面に「`.fold`は自動で付く」と書かれている場合だけ、`origami-simulator-01`と入力します。`Save`または「保存」を押します。
14. 保存先を選ぶ画面が出ず、自動で保存された場合は、ブラウザー右上の下向き矢印を押します。なければCtrlキーを押しながら`J`を押します。保存した項目の横のフォルダーの印、`Show in folder`、`Open file location`のいずれかを押します。
15. 自動で保存された元の名前が`.fold`で終わることを先に見ます。別の文字で終わる場合は、名前を変えずに止めます。`.fold`で終わる場合だけ、そのファイルを1回押し、Ctrlキーを押しながら`X`を押します。エクスプローラー上部の場所を示す欄へ手順12の保存先を入力してEnterキーを押し、Ctrlキーを押しながら`V`を押します。同じ名前があると表示されたら`キャンセル`を押して置き換えません。移せた場合は`F2`キーを押し、最後の`.fold`を残して名前を`origami-simulator-01.fold`にします。
16. 保存後、Windowsの印が付いたキーを押しながら`E`を押します。上部の場所を示す欄へ手順12の保存先を入力してEnterキーを押します。上部の`表示`を押し、続けて`表示`が出る場合はそれを押し、`ファイル名拡張子`（名前の最後の点から後ろを表示する項目です）に印を付けます。
17. `origami-simulator-01.fold`が1件あり、`.fold.fold`や`.fold.txt`で終わっていないことを見ます。ファイルを1回押し、Altキーを押しながらEnterキーを押します。`サイズ`または`大きさ`が0でなければ右上の`×`で閉じます。
18. Origami Simulatorへ戻り、`Import`または`Open`を押します。なければ`File`を押し、その中の`Import`か`Open`を押します。手順12の保存先を開き、`origami-simulator-01.fold`を選びます。
19. 正方形の中央に、上から中心、中心から下へ続く谷折りが見えれば成功です。この1件は8件のうちの1件目として数え、作り直しません。
20. 初めて印を付けるときは§11の手順で紙または記録用の写しを用意します。§13の`origami-simulator-01.fold`の行で、自作、保存、中身確認の3か所に印を付けます。担当者（この手順書を渡した人）へ、`Origami Simulatorの1件目を保存し、開き直せました`と知らせます。

**こうなっていればOKです**: `04-origami-simulator`に`origami-simulator-01.fold`があり、Origami Simulatorで開き直すと同じ2区切りの谷折りが見えます。ここまでできてから次へ進みます。

※ この住所、作者名、画面の文字と場所は、2026年8月26日時点で外部から確認していません。

### うまくいかないとき

- ページが開かない: 住所欄の文字と、画面に出た文章をそのまま担当者へ知らせ、ここで止めます。
- 空の正方形を出せない: 画面上部と左側に見える文字をすべて知らせ、最初から入っている見本で代用しません。
- 線を直接描けない: `Edit`、`Draw`、`Crease Pattern`、`Add Crease`があったかを知らせ、ここで止めます。
- 正方形を縦横4等分できない: `Grid`、`Snap`、`View`と、設定画面に見えた文字を知らせ、目分量では描きません。
- `.fold`を含む保存項目がない: `Export`または`Save`を押した後に見えた項目を上から順に知らせ、保存しません。
- 保存後の名前が`.fold`以外で終わる、または大きさが0: 名前だけを変えて代用せず、名前と保存場所を知らせて止めます。
- 保存後の名前が`.fold.fold`になった: そのファイルを残したまま保存し直さず、名前と保存場所を知らせて止めます。
- 同じ名前があると表示された: `Cancel`または「キャンセル」を押し、置き換えません。その名前と保存場所を担当者へ知らせます。
- 開き直せない: ファイルを消さず、`Import`または`Open`を押した後に出た文章を知らせて止めます。

## 2. ORIPAで1件だけ試す

ORIPAは三谷純氏が作ったソフトです。通常は名前が`.opx`で終わる形で保存します。今回必要な`.fold`を選べるかは確認できていないため、8件を描く前に1件だけ試します。

1. ブラウザーの住所欄へ次を入力し、Enterキーを押します。

   ```text
   https://github.com/oripa/oripa/releases
   ```

2. GitHub（ソフトやファイルの配布に使われるページ）の上部に`oripa / oripa`、中央に配布項目の一覧が出ることを見ます。`Releases`は、配布されている版の一覧です。
3. 一番上の項目に`Latest`があれば、その項目を使います。`Assets`（入手できるファイルの一覧）を押します。
4. `Source code`（ソフトを作る人向けの項目）で始まる2件は押しません。名前が`oripa`で始まり、`.jar`または`.exe`で終わるものが1件だけなら、それを押します。どちらもソフトを開くために使われる名前の最後の部分です。
5. 入手が終わったら、ブラウザー右上の下向き矢印、またはCtrlキーを押しながら`J`を押します。対象の横のフォルダーの印、`Show in folder`、`Open file location`のいずれかを押します。
6. 入手したものを2回続けて押してORIPAを開きます。`.jar`が開かない、警告が出る、パソコンの管理用の合言葉を求められる場合は、警告を無視して進めません。
7. ORIPAの上部にある`File`を押し、`New`を押します。白い正方形が出たら、`Grid`、`Snap`、または`View`を押した中の`Grid`を押します。`Grid Size`、`Grid Divisions`、`Set Grid`、`Configure Grid`のいずれかが出たら押し、数字の欄へ`4`を入力するか、一覧の`4`を押します。
8. `Valley`または`V`が画面上部か左側に直接あれば押します。なければ`Input`、`Line`の順に押し、その中の`Valley`または`V`を押します。
9. 上辺の中央から紙の中心までと、中心から下辺の中央まで、谷折りを2区切り描きます。
10. `File`を押し、`Save As`または`Export`を押します。どちらもなければ通常の`Save`は押さず、`File`の中に見えた文字を担当者へ知らせて止めます。
11. 保存画面の下部にある`Save as type`、`Files of type`、または「ファイルの種類」を押し、表示された一覧を一番下まで見ます。
12. 一覧に小文字の`.fold`を含む項目があれば、それを押します。保存先を次の場所にします。名前の欄へ`oripa-01.fold`と入力しますが、画面に「`.fold`は自動で付く」と書かれている場合だけ`oripa-01`と入力します。`Save`または「保存」を押します。フォルダーがなければ、保存画面の「新しいフォルダー」で`02-oripa`を作ります。

    ```text
    C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples\02-oripa
    ```

13. Windowsの印が付いたキーを押しながら`E`を押し、手順12の保存先を開きます。名前が正確に`oripa-01.fold`であり、`.opx`、`.fold.fold`、`.fold.txt`で終わっていないことを見ます。違う場合は名前を直さず止めます。正しい名前を1回押し、Altキーを押しながらEnterキーを押します。大きさが0でないことを見て閉じます。ORIPAへ戻り、`File`から`Open`または`Import`を押します。`oripa-01.fold`を開き、同じ谷折り2区切りが見えることを確認します。§13の同じ名前の行で、自作、保存、中身確認の3か所に印を付けます。この1件はORIPAの1件目として数えます。

**こうなっていればOKです**: 保存する種類の一覧に`.fold`があり、`oripa-01.fold`を保存して開き直せました。ORIPAの残り7件を作れます。

※ この住所、配布ファイル、画面の文字と場所は、2026年8月26日時点で外部から確認していません。

### `.fold`を選べなかったとき

1. `Cancel`または「キャンセル」を押し、保存を取り消します。
2. `.opx`を選びません。`.opx`で保存した後、名前だけを`.fold`へ変えることもしません。
3. 保存する種類の一覧に見えた文字を上から順に書き写します。
4. 担当者へ`ORIPAの保存画面で .fold を選べませんでした`と知らせ、書き写した一覧も渡します。
5. 次の4案のどれで進めるか、担当者の返事を待ちます。自分で決めてファイルを増やしません。

   - Orieditaを8件増やす: 公式6 + ORIPA 0 + Oriedita 16 + Origami Simulator 8 = 30件
   - Origami Simulatorを8件増やす: 公式6 + ORIPA 0 + Oriedita 8 + Origami Simulator 16 = 30件
   - OrieditaとOrigami Simulatorを4件ずつ増やす: 公式6 + ORIPA 0 + Oriedita 12 + Origami Simulator 12 = 30件
   - 補わず3つの出所で止める: 公式6 + ORIPA 0 + Oriedita 8 + Origami Simulator 8 = 22件。30件の収集は未完です

担当者が最初の3案のどれかを選んだ場合の保存名は§9.4にあります。4案目では30件にならないため、最終チェック表のORIPA 8行は未完のまま渡します。

### そのほか、うまくいかないとき

- 配布ページが開かない、`oripa / oripa`がない: 開いた住所と画面上部の文字を知らせて止めます。
- `Assets`に入手候補が複数ある: 見えている名前を上から順に知らせ、どれを使うか返事を待ちます。
- ORIPAを開けない: 入手した名前と表示された文章を知らせ、別の配布元から取り直しません。
- `File`、`New`、`Save As`、`Export`がない: 画面上部に見えている文字を知らせ、通常の`Save`は押さずに止めます。
- 縦横4等分の位置を表示できない: `Grid`、`Snap`、`View`と設定画面に見えた文字を知らせ、目分量では描きません。
- 保存時に同じ名前がある、保存後の名前が違う、または大きさが0: `Cancel`または「キャンセル」を押して置き換えません。表示された名前と保存場所を担当者へ知らせ、残り7件を作りません。
- 保存したものを開き直せない: ファイルを消さず、`Open`または`Import`の後に出た文章を知らせ、残り7件を作りません。

## 3. 4つの保存先をそろえる

1. Windowsの印が付いたキーを押しながら`E`を押します。
2. 上部の場所を示す欄へ次を入力し、Enterキーを押します。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples
   ```

3. 次の4フォルダーを作ります。すでにあるものは作り直しません。

   ```text
   01-official
   02-oripa
   03-oriedita
   04-origami-simulator
   ```

4. 上部の`表示`から`ファイル名拡張子`に印を付け、名前の最後の点から後ろまで常に見える状態にします。

**こうなっていればOKです**: `fold-samples`を開くと上の4フォルダーがあり、すでに作った1件目は対応するフォルダーにあります。

### うまくいかないとき

- 手順2の場所がない: `C:\Users\oltot\Documents\git-projects\ORIGAMI3`を開き、`verification`、`fold-samples`の順に作ってから、4フォルダーを作ります。
- 同じ名前がある: 置き換えず、そのフォルダーを開きます。中に見覚えのないものがあれば、名前を担当者へ知らせます。

## 4. 公式の見本6件を保存する

1. ブラウザーの住所欄へ次を入力し、Enterキーを押します。

   ```text
   https://github.com/edemaine/fold
   ```

2. ページ上部に`edemaine / fold`と表示されることを見ます。GitHubは、ファイルを公開するためのページです。
3. 中央の名前一覧で`LICENSE`を押します。`LICENSE`は、使ってよい条件が書かれたファイルです。なければ`COPYING`、`README`、`README.md`の順に押します。開いたら、ブラウザー上部の住所を§12の6行すべての「条件のページ」へ写し、確認日へ作業当日の日付を書きます。
4. `README`を開いた場合は、Ctrlキーを押しながら`F`を押し、`permission`（許可）、`copyright`（著作権）、`license`（使ってよい条件）を1語ずつ入力します。見つかった場所を読みます。
5. ファイルを手元へ保存すること、ORIGAMI3との確認に使うこと、この作業場所へ置いて担当者へ渡すことの3つをしてよいと読み取れる文章を、§12の6行の「今回の保存・確認・受け渡しをしてよいと判断した文章」へそのまま写します。
6. 3つのうち一つでも判断できなければ、6件の保存を始めません。開いたページの住所と、判断できなかった文章を担当者へ知らせます。
7. 条件を確認できたら、住所欄へ`https://github.com/edemaine/fold`をもう一度入力し、Enterキーを押します。中央の名前一覧で`examples`を押します。押した後、中央に複数の名前が並び、上部の住所の最後が`/examples`になれば目的の一覧です。

8. 中央の一覧で、名前が小文字の`.fold`で終わるものだけを上から見ます。フォルダー、画像、説明文は数えません。名前に`devil`または`rose`が含まれるものも選びません。この2語は英字の大文字と小文字のどちらで書かれていても選びません。
9. 条件に合う上から最初の6件を、1件目から6件目とします。同じ名前を2回選びません。元の名前を§12の対応する行へ書きます。
10. 1件目の名前を押します。ブラウザー上部の住所を§12の`official-01.fold`の「ファイルのページ」へ写します。内容が表示されたら、右上付近の`Raw`（ファイルだけを表示する項目）または`Download raw file`（ファイルだけを保存する項目）を押します。
11. 保存先を選ぶ画面が出たら、上部の場所を示す欄へ次を入力してEnterキーを押します。名前を`official-01.fold`にし、`Save`または「保存」を押します。

    ```text
    C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples\01-official
    ```

12. `Raw`を押した後に文字だけの画面が開いた場合は、Ctrlキーを押しながら`S`を押します。保存画面の`Save as type`または「ファイルの種類」で`All Files`（すべての種類）を選び、手順11の場所へ`official-01.fold`として保存します。
13. 自動で保存された場合は、Ctrlキーを押しながら`J`を押します。対象の横のフォルダーの印、`Show in folder`、`Open file location`のいずれかを押します。元の名前が`.fold`で終わることを見ます。別の文字で終わる場合は名前を変えず、担当者へ知らせて止めます。`.fold`で終わる場合だけ対象を1回押し、Ctrlキーを押しながら`X`を押します。エクスプローラー上部の場所を示す欄へ手順11の保存先を入力し、Enterキーを押します。Ctrlキーを押しながら`V`を押します。同じ名前があると表示されたら`キャンセル`を押して置き換えません。移せた場合だけ対象を1回押し、`F2`キーを押して、最後の`.fold`を残したまま`official-01.fold`にします。
14. 名前が正確に`official-01.fold`であることを見ます。`.fold.fold`なら名前を直さず、失敗として知らせます。`.fold.txt`なら、`Raw`の文字だけの画面から保存した場合に限り、`F2`を押して末尾の`.txt`を取り、`official-01.fold`にします。`.html`なら名前を変えず、失敗として知らせます。正しい`official-01.fold`を1回押し、Altキーを押しながらEnterキーを押します。`サイズ`または`大きさ`が0でないことを見て閉じます。次にファイルを右クリックし、`プログラムから開く`、`メモ帳`の順に押します。Ctrlキーを押しながら`F`を押し、`<!DOCTYPE html>`、`<html`を1つずつ入力します。どちらかが見つかった場合はインターネットのページを誤って保存しているため、保存成功にせず担当者へ知らせます。どちらもなく、文字のまとまりが表示されれば、保存せずメモ帳を閉じます。
15. 住所欄へ手順7の`examples`の住所をもう一度入力し、Enterキーを押します。2件目から6件目にも手順10～14を繰り返します。手順10では各ファイルページの住所を§12の対応する行へ写し、名前を順に`official-02.fold`、`official-03.fold`、`official-04.fold`、`official-05.fold`、`official-06.fold`にします。
16. §12の6行で、元の名前、ファイルのページ、条件のページ、条件の文章、確認日がすべて埋まったことを見て、保存欄へ印を付けます。§13の同じ最終名の行にも、条件確認、保存、中身確認の3つの印を付けます。公式の見本では、大きさが0ではなく、手順14の誤ったページの文字がないことを中身確認とします。

**こうなっていればOKです**: `01-official`に`official-01.fold`から`official-06.fold`までが1件ずつあり、6件とも大きさが0ではなく、元の名前と条件の記録があります。

※ 上の2つの住所、`examples`の現在の内容、使ってよい条件、画面の配置は、2026年8月26日時点で外部から確認していません。

### うまくいかないとき

- 住所が開かない、`edemaine / fold`と表示されない: 開いた住所と画面上部の文字を知らせ、別のページを選びません。
- `LICENSE`、`COPYING`、`README`がない: 中央の名前一覧を担当者へ知らせ、保存を始めません。

## 6. 8種類すべてで使う位置

紙は正方形です。紙の上を画面の上、紙の左を画面の左として、途中で紙を回しません。

```text
左上             上中央             右上


左中央             中心             右中央


左下             下中央             右下
```

- 上中央、下中央: 上辺または下辺のちょうど真ん中
- 左中央、右中央: 左辺または右辺のちょうど真ん中
- 中心: 縦と横の両方でちょうど真ん中
- 4分の1: 端から反対側までを4等分した最初の位置
- 4分の3: 端から反対側までを4等分した3番目の位置

1. 画面上部か左右で`Grid`、`Snap`、または`View`を押した中の`Grid`を押します。
2. `Grid Size`、`Grid Divisions`、`Set Grid`、`Configure Grid`のいずれかが出たら押します。数字の欄なら`4`と入力し、数字の一覧なら`4`を押します。
3. 正方形の縦横が4つずつ同じ間隔に分かれたことを見ます。位置を数字で入れる画面しかない場合は、画面内の説明に「4等分」の値がそのまま示されている場合だけ使います。値が示されていなければ、自分で換算せず止めます。

上の画面名がなく縦横を4等分できない場合は、目分量で描かず、画面上部と左右に見えている文字を担当者へ知らせます。位置合わせ用の線は自分で描く山折り・谷折りではありません。

§7で中心が線の始まりまたは終わりになっているときだけ、中心で区切って引きます。05の中央線は、上中央から下中央まで1本で引きます。

**こうなっていればOKです**: 位置合わせ用の表示を消すと、紙のまわりの4辺と、自分で引いた山折り・谷折りだけが残ります。
