# 30件のファイルを用意する手順

図形を描くのはOrieditaとORIPAだけです。Origami Simulatorでは、描いたファイルを読み込み、指定された保存を行います。
公式の見本6件、ORIPAで描いた図形から作る8件、Orieditaで描いた図形から作る8件、Origami Simulatorで読み直して保存する8件の合計30件を用意します。描く回数は16回です。
OrieditaとORIPAでは、この手順の8種類だけを自分で描き、ほかの人の作品は使いません。

## 最初に: 3つのソフトで何ができるかを見る（各5分）

Origami Simulatorの画面は利用者が確認済みです。この節で実際にメニューを調べるのは、画面が未確認のOrieditaとORIPAだけです。
各5分は、ソフトが開いた後にメニューを見る時間の目安です。入手や起動にかかる時間は含みません。

### 保存先と記録用の写しを用意する

1. Windowsの印が付いたキーを押しながら`E`を押し、エクスプローラー（ファイルやフォルダーを見る画面）を開きます。画面上部の場所を示す欄へ次を入力し、Enterキーを押します。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3
   ```

2. `verification`を開きます。なければ上部の「新規作成」、続けて「フォルダー」を押し、`verification`と入力してEnterキーを押してから開きます。
3. 同じ方法で`fold-samples`を作って開き、次の4フォルダーを作ります。すでにあるものは作り直しません。

   ```text
   01-official
   02-oripa
   03-oriedita
   04-origami-simulator
   ```

4. `verification`へ戻り、`fold-work`を作ります。その中へ`oriedita-svg`と`oripa-svg`を作ります。ここには途中で使うファイルだけを置き、30件には数えません。
5. `fold-samples`を開きます。エクスプローラー上部の「表示」を押し、「ファイル名拡張子」（名前の最後の点から後ろを表示する項目です）に印を付けます。以後、`.fold.fold`や`.fold.txt`のような誤った名前を見分けられます。
6. 紙へ記録する場合は、この文書を表示した画面でCtrlキーを押しながら`P`を押し、使用するプリンター、`Print`または「印刷」の順に押します。印刷できたら手順7～10は行わず、「Orieditaでできることを調べる」へ進みます。書く場所が足りないときは別の紙にソフト名を書き、その下へ続けます。
7. 画面で記録する場合は、エクスプローラーで次の場所を開きます。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\docs
   ```

8. `ファイル収集の手順.md`を1回押し、Ctrlキーを押しながら`C`を押します。次の場所を開き、Ctrlキーを押しながら`V`を押します。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples
   ```

9. 写しを1回押して`F2`キーを押し、`収集チェック記録.md`と入力してEnterキーを押します。同じ名前がある場合は「キャンセル」を押し、既存のものを開いたり置き換えたりせず、担当者（この文書を渡し、完成品または途中の報告を受け取る人）へ知らせて止めます。
10. `収集チェック記録.md`を右クリックし、「プログラムから開く」、「メモ帳」の順に押します。以後、§11～§13の空欄へ入力したら、Ctrlキーを押しながら`S`を押します。

**こうなっていればOKです**: 4つの最終保存先と2つの途中作業用フォルダーがあり、紙または`収集チェック記録.md`へ記録できます。

### Orieditaでできることを調べる

Orieditaの配布ページと画面は、2026年8月26日時点で外部から確認していません。次は配布ページの候補です。

1. ブラウザー（インターネットのページを見る画面）の住所欄へ次を入力し、Enterキーを押します。

   ```text
   https://oriedita.github.io/download.html
   ```

2. `Windows`または`Download`があれば押します。GitHub（ソフトの配布にも使われるインターネット上の場所）の配布一覧が開いた場合は、一番上の`Latest`と表示された項目で`Assets`（入手できるファイルの一覧）を押します。
3. 上のページを開けない場合は、住所欄へ次を入力し、Enterキーを押します。

   ```text
   https://github.com/oriedita/oriedita/releases
   ```

4. `Source code`で始まる項目は押しません。名前が`oriedita`で始まり、`.jar`または`.exe`で終わるもの（Orieditaを動かすために入手するファイル）が1件だけなら押します。複数ある、または1件もない場合は、`Assets`に見える名前を上から順に§11へ写し、担当者へ知らせて止めます。
5. 入手後、ブラウザー右上の下向き矢印を押します。なければCtrlキーを押しながら`J`を押します。対象の横にあるフォルダーの印、`Show in folder`、`Open file location`のいずれかを押します。
6. 入手したものを2回続けて押します。警告、管理用の合言葉を求める画面、または開けないという文章が出た場合は、無理に進めず、その文章と入手した名前を担当者へ知らせます。
7. Orieditaが開いたら、上部に並ぶメニューの名前を左から順に§11へ写します。
8. 左端のメニュー見出しを1回押します。中に出た文字を、灰色の文字も含めて上から順にすべて写します。右向きの印がある行は、その行にマウスを合わせ、右側に出た文字も写します。項目そのものは押しません。
9. Escキーを押して一覧を閉じ、次のメニュー見出しを押します。右端まで同じ作業を繰り返します。
10. 写した内容から、新しい図形を始める候補を見ます。候補は`File`の中の`New`または`New File`、あるいは`Pattern`の中の`New`や`Create`です。実際にあった文字と、押す順番を§11へ写します。
11. 線を引く候補を見ます。候補は`Input`、`Line`、`Mountain`、`Valley`、`M`、`V`です。山折りと谷折りを別々に選べることが分かる文字を§11へ写します。
12. 位置を合わせる候補を見ます。候補は`View`または`Pattern`の中の`Grid`や`Snap`です。4等分を選べる数字または設定名があれば、その文字も写します。
13. 保存の候補を見ます。候補は`File`の中の`Save As...`、`Save...`、`Save`、`Export...`です。実際にあった文字と押す順番をすべて§11へ写します。
14. 新しい図形を始める候補を実際に押し、何も描かれていない正方形を出します。保存の候補を一つ押し、`Save as type`、`Files of type`、または「ファイルの種類」を押します。候補が複数ある場合は、`Cancel`または「キャンセル」で閉じてから、残りも一つずつ開きます。保存画面が出ず、勝手に保存されたように見える場合は、画面に見える文章を§11へ写して担当者へ知らせ、止めます。
15. 各一覧に`.fold`があるかを見ます。なければ`.svg`があるかを見ます。`.svg`は、Origami Simulatorが読み込める、名前の最後がこの4文字で終わるファイルです。表示された種類を上から順に§11へ写し、`Cancel`または「キャンセル」を押します。
16. 上部メニューの全内容、新しく始める順番、山折り、谷折り、位置合わせ、保存の順番、`.fold`と`.svg`の有無を担当者へ知らせます。

**こうなっていればOKです**: 実際の画面から、空の正方形を出す順番、山折りと谷折りを引く順番、4等分する順番、`.fold`または`.svg`で保存する順番を記録できました。

次のどれかに当てはまる場合は§2へ進みません。

- 空の正方形を出す項目がない。
- 山折りと谷折りを別々に選べない。
- 正確な4等分の位置を使えない。
- `.fold`と`.svg`のどちらも保存する種類にない。
- メニューの意味を判断できない。

### ORIPAでできることを調べる

   https://github.com/oripa/oripa/releases

### Origami Simulatorで確認済みのこと

住所は次で正しいことを利用者が確認済みです。パソコンへ入れる必要はありません。

```text
https://origamisimulator.org/
```

上部メニューは、左から次の順です。

```text
File ▼ ／ Examples ▼ ／ View ▼ ／ Pattern ／ Simulation ／ About
```

`File`を押した中身は、上から次の順です。これは利用者が実際の画面で確認した文字です。

```text
Import... (SVG / FOLD)
Design Tips
─────
Record animated GIF...
Record video...
Save PNG screenshot...
─────
Save Simulation as FOLD...
Save Simulation as STL...
Save Simulation as OBJ...
─────
Save Pattern as SVG...
```

画面下部と右上には次があります。

```text
View Mode: Material / Strain
Fold Percent: 60%     Flat ←→ Folded のつまみ

右上: Show Advanced Options
```

Origami Simulatorでは新しい図形を描けません。`Reset`も、新しい図形を作るボタンではありません。この手順で使う操作は、読み込みの`File`→`Import... (SVG / FOLD)`と、保存の`File`→`Save Simulation as FOLD...`だけです。大文字を含む英字は、画面に出る文字をそのまま示しています。

`Examples`は最初から入っている見本を読むための項目です。今回の8件は自分で描いた図形を使うため、`Examples`は押しません。

## 2. まず2件だけ作る

Orieditaで図形01を描き、その図形から`oriedita-01.fold`を作ります。次に同じファイルをOrigami Simulatorで読み直し、`origami-simulator-01.fold`を作ります。2件とも完成するまで残りへ進みません。

### Orieditaで図形01を描く

1. §11に記録した、Orieditaで新しい図形を始める順番をそのまま押します。記録が`File`→`New`なら、その2つだけを押します。別の順番なら、記録した実際の文字だけを使います。
2. §11に記録した位置合わせの順番を押し、正方形を縦横4等分します。4等分になったことを画面で判断できなければ、目分量で続けません。
3. §11に記録した谷折りの順番を押します。上辺の中央から紙の中心まで、続けて中心から下辺の中央まで、谷折りを2区切り引きます。
4. 画面に、正方形の真ん中を上から下へ通る谷折りだけが見えることを見ます。
5. §11に記録した保存の順番を押します。

### Orieditaで`.fold`を選べた場合

1. 保存する種類で`.fold`を含む項目を押します。
2. 保存先を次にします。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples\03-oriedita
   ```

3. 名前の欄へ`oriedita-01.fold`と入力します。画面に「`.fold`は自動で付く」と書かれている場合だけ、`oriedita-01`と入力します。
4. `Save`または「保存」を押します。同じ名前があると表示された場合は`Cancel`または「キャンセル」を押し、置き換えず担当者へ知らせて止めます。
5. §11の「Orieditaの保存経路」と、§13の`oriedita-01.fold`の備考へ`直接`と書きます。次のSVGの節と、その次の「指定名へそろえる」の節は行わず、「同じ図形をOrigami Simulatorで読み直して保存する」へ進みます。

### Orieditaで`.fold`を選べず、`.svg`を選べた場合

1. 保存する種類で`.svg`を含む項目を押します。
2. 保存先を次にします。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-work\oriedita-svg
   ```

3. 名前の欄へ`oriedita-source-01.svg`と入力します。画面に「`.svg`は自動で付く」と書かれている場合だけ、`oriedita-source-01`と入力します。
4. `Save`または「保存」を押します。同じ名前があると表示された場合は`Cancel`または「キャンセル」を押し、置き換えず担当者へ知らせて止めます。この途中ファイルは30件に数えません。
5. ブラウザーで`https://origamisimulator.org/`を開きます。読み込み前に中央へ何が見えるかを、色、形、向きが分かる言葉で§11へ書きます。上部の`File`を押し、`Import... (SVG / FOLD)`を押します。
6. 手順2の場所を開き、`oriedita-source-01.svg`を1回押して「開く」を押します。
7. ファイルを選ぶ画面が閉じた後、中央へ何が見えるかを同じ書き方で§11へ書きます。読み込み前後で変わった場所を一つ以上書きます。変化を見分けられない場合や、読み込みの失敗を示す文章が出た場合は保存せず、前後の記録と画面の文章を担当者へ知らせて止めます。変化を見分けられた場合は`File`を押し、`Save Simulation as FOLD...`を押します。
8. 次の「Origami Simulatorで保存したものを指定名へそろえる」の手順を使い、保存先を`03-oriedita`、最終名を`oriedita-01.fold`にします。
9. §11の「Orieditaの保存経路」と、§13の`oriedita-01.fold`の備考へ`SVG経由`と書きます。

SVGを経由した場合、`oriedita-01.fold`はOrigami Simulatorの保存操作で作られますが、Orieditaで描いた図形から作った8件の一つとして記録します。

### Origami Simulatorで保存したものを指定名へそろえる

1. 保存先を選ぶ画面が出た場合は、上部の場所を示す欄へ指定された保存先を入力し、Enterキーを押します。名前の欄へ指定された最終名を入力し、`Save`または「保存」を押します。同じ名前があると表示された場合は`Cancel`または「キャンセル」を押し、置き換えず担当者へ知らせて止めます。保存できた場合は手順7へ進みます。
2. 保存先を選ぶ画面が出ず、自動で保存された場合は、ブラウザー右上の下向き矢印を押します。なければCtrlキーを押しながら`J`を押します。
3. 対象の横にあるフォルダーの印、`Show in folder`、`Open file location`のいずれかを押します。
4. 自動保存された元の名前が`.fold`で終わることを見ます。別の文字で終わる場合は、名前を変えず担当者へ知らせて止めます。
5. `.fold`で終わる場合だけ対象を1回押し、Ctrlキーを押しながら`X`を押します。指定された保存先を開き、Ctrlキーを押しながら`V`を押します。
6. 同じ名前があると表示されたら「キャンセル」を押し、置き換えず担当者へ知らせて止めます。移せた場合は対象を1回押し、`F2`キーを押して指定された最終名にします。名前を変える途中で同じ最終名があると表示された場合も、Escキーまたは「キャンセル」を押し、置き換えず担当者へ知らせて止めます。
7. Windowsの印が付いたキーを押しながら`E`を押します。上部の場所を示す欄へ指定された保存先を入力し、Enterキーを押します。上部の「表示」を押し、「ファイル名拡張子」に印が付いていることを見ます。
8. 指定された最終名と一文字ずつ同じで、`.fold.fold`や`.fold.txt`ではないことを見ます。対象を1回押し、Altキーを押しながらEnterキーを押します。`サイズ`または`大きさ`が0でないことを見て閉じます。

### 同じ図形をOrigami Simulatorで読み直して保存する

1. Windowsの印が付いたキーを押しながら`E`を押し、次の場所を開きます。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples\03-oriedita
   ```

2. 名前が正確に`oriedita-01.fold`で、`.fold.fold`や`.fold.txt`ではないことを見ます。Altキーを押しながらEnterキーを押し、大きさが0でないことを見て閉じます。
3. ブラウザーで`https://origamisimulator.org/`を開きます。Orieditaから直接保存した場合は、読み込み前に中央へ何が見えるかを、色、形、向きが分かる言葉で§11へ書きます。上部の`File`を押し、`Import... (SVG / FOLD)`を押します。
4. 手順1の場所を開き、`oriedita-01.fold`を1回押して「開く」を押します。ファイルを選ぶ画面が閉じた後、直接保存の場合は中央に見えるものと、読み込み前から変わった場所を§11へ書きます。変化を見分けられない場合や、失敗を示す文章が出た場合は、記録と画面の文章を担当者へ知らせて止めます。SVG経由の場合は直前に同じ図形を読み込んでいるため、見た目が同じでも構いません。画面下部のつまみや`Reset`は操作しません。
5. 上部の`File`を押し、`Save Simulation as FOLD...`を押します。
6. 前の節の手順を使い、保存先を次の場所、最終名を`origami-simulator-01.fold`にします。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples\04-origami-simulator
   ```
