# 30件のファイルを用意する手順

1. OrieditaとORIPAで、8種類の図形をそれぞれ描いて保存する（16回）
2. Orieditaで作ったものをOrigami Simulatorで開き直して保存する（8回）
3. 公式の見本を6件ダウンロードする

いま何をすればよいか分からなくなったら、§7のチェック表を見てください。

## 1. Orieditaを開く

1. Windowsキーを押し、`PowerShell`と入力して開きます。
2. 次を貼り付けてEnterキーを押します。

   ```text
   java -jar "C:\Users\oltot\Downloads\oriedita-1.1.3.jar"
   ```

入手元は`https://github.com/oriedita/oriedita/releases`で確認済みです。

→ Orieditaの画面が開いたら、PowerShellを閉じずに§2へ進みます。

→ 30秒待っても開かない場合は、PowerShellに出た文を最初から最後まで担当者へ送って止めます。

→ `java`が見つからないという文は、Java（この`.jar`を開くために必要なもの）が入っていない可能性を示します。自分で入れず、その文を担当者へ送ります。

## 2. メニューの中身を教えてください

1. Orieditaの上にある左端の見出しだけを押します。中の項目は押しません。
2. 中の文字が見える状態で画面全体の写真を1枚撮り、担当者へ送ります。
3. 写真を送った後、残りの見出しも一つずつ押し、中の文字を短く書いて送ります。文字が多ければ、担当者が指定した見出しの写真を追加で送ります。

担当者が知りたいのは次の2点です。分からなければ、`分かりません`と伝えて構いません。

- 新しく描けるか
- 保存する種類に`.fold`、なければ`.svg`があるか

→ 写真を送ったら、ここで止めます。担当者がこの手順書を更新するまで、図形を描いたり保存したりしません。

→ ORIPAはまだ入手しません。担当者から入手先と開き方を受け取った後、手順1～3を同じように行い、全見出しの中の文字を送ります。

## 3. 担当者の返事後に16件を作る

→ OrieditaとORIPAの両方について担当者の返事を受ける前は、この節を行いません。

### 保存先を作る

1. Windowsキーを押しながら`E`を押し、上の場所欄へ次を貼り付けてEnterキーを押します。

   ```text
   C:\Users\oltot\Documents\git-projects\ORIGAMI3\verification\fold-samples
   ```

2. 表の保存先がなければ、上の「新規作成」→「フォルダー」を押し、表の名前を一つずつ入力して作ります。

| 作る所 | 保存先 | 保存名 |
|---|---|---|
| Oriedita | `03-oriedita` | `oriedita-01.fold`～`oriedita-08.fold` |
| ORIPA | `02-oripa` | `oripa-01.fold`～`oripa-08.fold` |
| Origami Simulator | `04-origami-simulator` | `origami-simulator-01.fold`～`origami-simulator-08.fold` |
| 公式 | `01-official` | `official-01.fold`～`official-06.fold` |

### Orieditaで8件作る

3. 担当者が書き足した実際の操作だけを使い、Orieditaで§6の図形01～08を描きます。
4. 保存する種類に`.fold`があれば選びます。なければ`.svg`（線を受け渡すためのファイル）を選び、Origami Simulatorで`.fold`として保存します。
5. 1件保存するたびに、名前が表と同じで、大きさが0でないことを見ます。

### ORIPAで8件作る

6. Orieditaの手順3～5をORIPAでも行い、同じ8種類を保存します。

→ Oriedita 8件とORIPA 8件がそろったら§4へ進みます。

→ 画面が担当者から教わったものと違う場合は、そこで止めて写真を送ります。

## 4. Origami Simulatorで8件を保存する

1. ブラウザー（インターネットを見る画面）で`https://origamisimulator.org/`を開きます。
2. `File`→`Import... (SVG / FOLD)`を押します。
3. `03-oriedita`の`oriedita-01.fold`を選び、「開く」を押します。
4. `File`→`Save Simulation as FOLD...`を押します。
5. `04-origami-simulator`へ`origami-simulator-01.fold`として保存します。
6. 番号を02、03の順に増やし、08まで同じ操作を行います。

→ `origami-simulator-01.fold`～`origami-simulator-08.fold`がそろったら§5へ進みます。

→ 保存先を選ぶ画面が出ない、または読み込めない場合は、見えている文を担当者へ知らせて止めます。

## 5. 公式の見本を6件保存する

1. ブラウザーで`https://github.com/edemaine/fold`を開きます。
2. `LICENSE`（使ってよい条件）または`README`（説明）を押し、保存して担当者へ渡してよいと分からない場合は止めます。
3. 最初のページへ戻り、`examples`を押します。
4. 名前が`.fold`で終わるものを上から6件選びます。名前に`devil`または`rose`が入るものは選びません。
5. 1件目の名前を押し、`Raw`（ファイルだけを表示）または`Download raw file`（ファイルだけを保存）を押します。
6. `01-official`へ`official-01.fold`として保存します。
7. 残りも同じ順で`official-02.fold`～`official-06.fold`として保存します。

→ 6件の名前が正しく、大きさが0でなければ§7へ進みます。

→ この住所と現在の表示は外部から確認していません。ページが開かない、表示が違う、または条件が分からない場合は、画面の写真を担当者へ送って止めます。

## 6. 描く8種類

紙は正方形のまま回しません。中央は紙の真ん中、1/4と3/4は辺を4等分した位置です。

| 番号 | 描く線 |
|---:|---|
| 01 | 上辺の中央→中心→下辺の中央。2本とも谷折り |
| 02 | 左上→中心→右下。2本とも山折り |
| 03 | 左上→中心→右下は山折り。右上→中心→左下は谷折り |
| 04 | 上辺の中央→中心→下辺の中央は谷折り。左辺の中央→中心→右辺の中央は山折り |
| 05 | 左から1/4、中央、3/4に、上辺から下辺まで縦線。谷折り、山折り、谷折りの順 |
| 06 | 上・右・下・左の各辺の中央を結ぶひし形。谷折り、山折りを交互にする |
| 07 | 中心から四隅へ山折り4本。中心から各辺の中央へ谷折り4本 |
| 08 | 上辺1/4→右から1/4・上から1/4→左から1/4・上から1/2→右から1/4・上から3/4→下辺1/4。谷、山、谷、山の順 |

→ 1つのソフトで01～08を1回ずつ描きます。同じ番号を作り直して増やしません。
