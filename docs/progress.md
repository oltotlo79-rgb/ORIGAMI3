## 2026-08-05 - Task 2-2修正2 - 折り線が既存の逆向きの折り目と重なるときに知らせるよう修正

- 折り線の一部に反対向きの折り目(山のところへ谷を引くなど)が既にある場合、何も知らせずに折れてしまっていた。折り上がりの形は同じでも、折っている途中の形が求まらず手順の再生アニメーションが崩れるため、日本語の警告を出すようにした

## 2026-08-05 - Task 2-2修正 - 補助線の上で折れない・手順が再生できなくなる2つの欠陥を修正

- 補助線と重なる位置で折ると、重なった部分だけ線が入らず面が分かれないまま「成功」を返し、紙全体が裏返る状態になっていた。重なった補助線を折り線(山/谷)に変えるようにして解消した。念のため「線が横切ったのに面が分かれていない」場合は展開図を変えずに中止する安全弁も入れた
- 折り手順に残す角度の指定が線の番号だったため、あとから別の折りを加えて線が分割されると手順を再生できなくなっていた。指定を「展開図の上の線分+角度」で持つ方式に変え、再生時にその線分に乗る全ての断片を探して駆動するようにした(重なり順を代表の点で保存しているのと同じ考え方)
- あわせて、既存の折り線と重なる区間にも角度の指定を作るようにし(線種は既存のまま)、同じ警告が何度も出る問題と、頂点探索の無駄な繰り返しも直した
- テストは9件→10件(補助線との重なりの検証を配置・重なり順まで拡張し、線が分割された後も手順どおりに折れて畳んだ位置が一致することを確かめる新規1件を追加)。全5検査合格(Rust 112件・画面53件)
- 既知の問題: 折り線と重なった補助線は元に戻せない(折り線に変わる)。既存の折り線と完全に一致する再折りは引き続き未対応
