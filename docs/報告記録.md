### 1. 折り鶴の7手目が誤りであることを、解析的に確定した

**画像だけでなく、数式で示せた。**

**6手目（鳥の基本形）の紙の形**

```
c = 1 − √2/2
a = (√2 − 1)/2
T = (0, 0)        先端
R = (0, c)        付け根

紙の実polygon和集合   |x|/a + 2|y − 1/2| <= 1 を満たす領域
```

**付け根 R を通る折り線について、先端の反射先は  T' = R + (2uuᵀ − I)(T − R)。**

**左右対称な折り線を角度 ±α で表すと**

```
T'_A = R + c(sin2α,  cos2α)
T'_C = R + c(−sin2α, cos2α)
```

**「反射先が紙の外にある」条件を解くと**
