# 観察する人の手順

## 1. 始める前

1. 有効な参加者を15名そろえる。内訳は、初めて使う人5名、展開図を使ったことがある人5名、折り方を作ったことがある人5名とする。
2. 同じ人を複数の区分へ数えない。画面を作った人、開発に関わった人、事前に課題文を見た人は数えない。
3. 全員に同じ版、同じ開始状態、同じ折り鶴の課題文を使う。
4. 匿名番号01～15を割り当てる。氏名や連絡先との対応表は作らない。
5. [参加についての文](consent.md)を読み、参加してよいかを確かめる。「はい」と答えた人だけ始める。
6. 画面の録画、音声、氏名、連絡先は取らない。録画や録音の機器を動かさない。
7. 秒数を測る時計と、[匿名の集計様式](record-sheet.md)を用意する。

## 2. 課題を伝える

1. [お願いする5つのこと](tasks.md)を、番号順に、書いてあるとおり一度だけ読む。
2. 各課題文の最後まで読み終えた瞬間を0秒として、時計を始める。
3. 参加者が聞き取れなかった場合だけ、同じ課題文を一字も変えずにもう一度読む。言葉を足したり、別の言い方へ変えたりしない。
4. 参加者が課題の結果へ到達した瞬間に秒数を止める。到達できないまま中止した場合は、中止した瞬間の秒数を観察終了秒へ記録する。

## 3. 絶対に助けない

観察する人は、課題中に参加者を**助けてはいけない**。助けると、説明を受けずに使えるかを測れなくなる。

- 画面を指さない。
- 代わりにマウスやキーを操作しない。
- 押しどころの名前、場所、押し方を教えない。
- 次に何をすればよいかを教えない。
- 正解を示唆しない。「合っています」「惜しいです」「戻ってください」「もう少しです」などと言わない。
- 表情、うなずき、視線で正解を示さない。
- 画面にある言葉の意味を説明しない。
- 参加者が自分で画面内の案内を見ることは止めないが、その案内の場所は教えない。

質問を受けたときは、次の文だけを読む。

**この確認では、操作の説明はできません。思うように続けてください。やめたいときは知らせてください。**

## 4. 数え方

### 説明なし完了と秒数

- 観察する人が操作方法を説明せず、代わりに操作せずに結果へ到達した場合を、説明なし完了1とする。
- 参加者が自分で画面内の案内を見て到達した場合も説明なし完了1とし、案内参照回数を別に数える。
- 秒数は小数点以下を切り上げ、整数で記録する。

### 停止

- 次にすることを探して操作が止まったと観察できた時点から、再び操作するまでを1回と数える。短い停止も数え、30秒になるまで待ってから数え始めない。
- 画面の変化を待つ必要がある時間は停止に数えない。
- 各停止の秒数を測り、停止回数、最長停止秒、30秒以上の停止回数を記録する。

### 誤操作と取り消し

- 課題の結果へ進まず、やり直しや別の場所への移動が必要になった操作を、誤操作1回と数える。
- 連続した押下や文字入力など、ひとまとまりの操作は1回と数える。
- 取り消す操作をした回数は、誤操作回数とは別に数える。
- 同じ操作を3回以上続けたひとまとまりは1回と数える。

### 質問と画面内の案内

- 参加者が観察する人へ問いかけるたびに、質問1回と数える。同じ問いを繰り返した場合も、その都度数える。
- 質問の文章は書かず、「言葉の意味」「行く場所」「次にすること」「その他」のどれかへ分類する。
- 参加者が画面内の説明を開く、または読もうとして注目するたびに、案内参照1回と数える。同じ説明を閉じて再び見た場合は、もう1回数える。
- 失敗や注意を知らせる表示が新しく出るたびに1回と数える。

### 重大な行き止まり

次のどれかが起きた場合は、重大な行き止まり1とし、説明なし完了を0にする。

1. 観察する人が代わりに操作しなければ続けられない。
2. アプリを再起動しなければ続けられない。
3. 参加者が作ったものが失われた。
4. 次の課題へ進めない。

複数が起きた場合は分類を「複数」とする。安全を守るため、または参加者が中止を求めたために止める場合を除き、観察する人から介入しない。

## 5. 課題ごとの終わり

1. 結果へ到達したら、成功か失敗かを参加者へ伝えず、「この課題はここで終わりです」とだけ言う。
2. すべての数値、0/1、分類をその場で記入し、空欄がないことを確かめる。
3. 参加者が途中でやめたいと言ったら、すぐに止める。続けるよう説得しない。その方の記録は集計に入れず削除する。
4. 5課題が終わったら、「ご協力ありがとうございました」と伝える。結果の良し悪しは伝えない。
5. 次の参加者を始める前に、同じ開始状態へ戻す。この作業は参加者がいないところで行い、課題中の操作として数えない。

## 6. 終了後の確認

1. 有効な参加者が各区分5名、合計15名であることを確かめる。不足、重複、同意なし、途中中止があれば、同じ区分の別の人で補う。
2. 15名×5課題の75行がすべてあり、欠測が0であることを確かめる。
3. 匿名番号以外に、氏名、連絡先、話した文章、作品の内容が書かれていないことを確かめる。
4. 75行を[匿名の集計様式](record-sheet.md)の集計欄へ足し合わせる。失敗した行を分母から外さない。
