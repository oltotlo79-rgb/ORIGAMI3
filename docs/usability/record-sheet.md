# 匿名の集計様式

## 記入の決まり

- 有効な参加者は15名とし、1人につき5課題、合計75行を記録する。
- 匿名番号01～05は初めて使う人、06～10は展開図を使ったことがある人、11～15は折り方を作ったことがある人へ割り当てる。同じ人を2回数えない。
- 数える項目は0以上の整数で書く。秒数は小数点以下を切り上げる。
- 「0/1」の項目は、いいえを0、はいを1とする。
- 説明なしで終えられなかった場合、説明なし完了を0、完了秒を-1とし、観察終了秒にはその課題を終えた時点の秒数を書く。
- 測れなかった数値は-1、欠測は1とする。測れた行は欠測を0とする。空欄を残さない。
- 主な誤操作は「なし」「違う押しどころ」「違う場所」「同じ操作の反復」「取り消し」「その他」から1つ選ぶ。複数あるときは最も回数が多いもの、同数なら先に起きたものを選ぶ。
- 主な質問は「なし」「言葉の意味」「行く場所」「次にすること」「その他」から1つ選ぶ。複数あるときは最も回数が多いもの、同数なら先に起きたものを選ぶ。
- 重大な行き止まりの分類は「なし」「観察者が操作」「再起動」「作ったものが消失」「次へ進めない」「複数」から1つ選ぶ。
- 言葉原因停止は、画面にある言葉が分からないことを理由に質問、操作の中断、別の場所への迷いが起きた場合を1とする。

## 課題番号

| 番号 | お願いすること |
|---:|---|
| 1 | 新しい紙を作る |
| 2 | 山折りまたは谷折りの折り線を引く |
| 3 | 紙を折る |
| 4 | 手順を記録して再生する |
| 5 | PDFの折り図を書き出す |
