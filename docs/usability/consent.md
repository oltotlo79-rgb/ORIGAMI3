# 利用確認への参加について

## 目的

折り紙の設計を初めて行う人にも、画面が分かりやすいかを確かめます。お願いするのは5つです。これは参加する方の能力を測る試験ではありません。分かりにくいところがあれば、画面を直すための手掛かりにします。

## 参加は自由です

参加するかどうかは自由です。参加しないことによる不利益はありません。始めた後でも、理由を言わずにいつでもやめられます。やめたいときは、観察する人へ伝えてください。

## 記録すること

氏名の代わりに、その場で割り当てる匿名番号を使います。匿名番号と、次の数値または決められた分類だけを記録します。

- 5つのお願いを、説明なしで終えられたか
- 終えるまでの秒数
- 手が止まった回数と、最も長く止まった秒数
- 誤った操作、取り消し、質問の回数
- 画面内の案内を見た回数
- 同じ操作を繰り返した回数
- 失敗や注意の表示が出た回数
- 続けられなくなったか、その理由の分類

話した内容を文章のまま書き残すことはしません。質問は回数と分類だけを記録します。

## 取りません

- **画面の録画は取りません。**
- **音声は取りません。**
- **氏名は取りません。**
- **連絡先は取りません。** メールアドレス、電話番号、住所も取りません。

作品の内容、個人用の保存場所、顔写真も取りません。匿名番号と本人を結び付ける一覧は作りません。

## 途中でやめたときと記録の保管

途中でやめた場合、その方の記録は集計に加えず、観察する人が削除します。匿名番号と本人を結び付ける情報を残さないため、確認を終えてその場を離れた後は、本人の記録だけを探し出すことはできません。

匿名番号ごとの記録は、全体の集計を確定してから90日以内に削除します。全員分を足し合わせた数だけは、画面を改善したか確かめるために残すことがあります。

## 同意の確認

次の問いに「はい」と答えた場合だけ始めます。「いいえ」と答えた場合や返答がない場合は始めず、記録も残しません。

**上の説明を読み、参加は自由で途中でもやめられること、画面の録画・音声・氏名・連絡先を取らないことを理解しました。参加してもよいですか。**

- はい
- いいえ
